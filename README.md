## What Is DXSH Corporation?

DXSH Corporation is a web portfolio built to display creative editing work in a clear, visual layout. It gathers photo and video pieces in one place, highlighting careful color work, detailed retouching, animated graphics, and fluid transitions.

The site is aimed at people reviewing creative production samples, editing showcases, and visual storytelling. The work reflects common pipelines around Adobe Photoshop, Lightroom, Premiere Pro, and After Effects.

## Getting the Project Locally

Clone the repo, then move into the project folder:

```bash
git clone https://github.com/peter-fisher30/dxsh-motion-graphics-hub.git
cd REPO
```

This site is HTML-based, so you can open the main HTML file directly in a browser. For a steadier local experience, serve the files with any lightweight static server.

Python example:

```bash
python -m http.server 8000
```

Open `http://localhost:8000` in your browser afterward.

## FAQ

### How can I open the portfolio?

Use the published project URL in a browser, or clone the repo and serve it locally with a static web server.

### Can I review edits before they go live?

Yes. Start a local static server, open that address in a browser, and inspect pages and media before you deploy.

### Where does configuration live?

Structure and behavior come from the HTML, CSS, navigation, and asset files. No separate settings UI is documented for this project.

### How do I change the work on display?

Swap or add portfolio media and content, then adjust the HTML so every reference points at the right file.

### An image or video is missing. What should I check?

Make sure the file is in the expected folder, that the name and case match exactly, and that the HTML path matches the real path on disk.

### How do I track new releases?

Watch the repository for HTML changes, refreshed creative assets, and new portfolio builds.
